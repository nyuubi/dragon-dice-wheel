# Dragon Dice Wheel

**Dragon Dice Wheel** is a non-transitive, strategy-focused web game based on non-standard probability distributions and figures from German mythology. Players go head-to-head against a CPU opponent in a 5-round series, using custom-weighted dice and character abilities to outmaneuver the odds.

### Description

In **Dragon Dice Wheel**, victory isn't just about rolling high—it's about understanding statistical match-ups and managing resources. Players choose a mythic German trope (such as *Loreley*, *Heinzelmännchen*, *Klabautermann*, or the *Späti-Kobold*), each tied to a uniquely faces-distributed die and a distinct tactical ability. Across 5 rounds, players must decide when to spend tokens to force rerolls, apply flat modifiers, or declare high-stakes "All-In" gambits to gain a long-run mathematical edge over their opponent.

### Core Features

* **Non-Transitive Dice Distributions:** Every trope uses a uniquely weighted die, creating dynamic match-ups where no single die is universally superior.
* **Trope-Specific Abilities:** Tactical options allow players to spend earned tokens to manipulate rolls, force opponent rerolls, or alter round win conditions.
* **Flexible Opponent Setup:** Choose to face a randomly generated opponent or manually select a target trope to test specific probability match-ups.
* **Interactive Arena UI:** Features real-time score tracking, round calculation breakdowns, custom-badged event logs, and animated 2D dice spins.
